## 1. 版本定位

GPT TalkEnhancer v0.5.1 是基于 v0.5.0 正确性基线的 **Navigation Performance & Reliability Release**。

本版本不新增产品功能，继续只保留：

1. Conversation Timeline / Question List
2. Prompt Picker / Prompt Library

本次目标是提高 Chat / Work 长会话导航速度，同时保持 v0.5.0 已冻结的 Restore、Tail Verification、post-settle 与 fail-closed 语义。

## 2. 主要完成项

### 2.1 Chat 首次会话 UI 初始化

修复首次进入较长 Chat 会话时正文已出现、但 Timeline / Questions 因 conversation identity 稳定较晚而暂时不显示的问题。

Chat sidebar selection 后使用窄的 identity settle retry：`240ms → 600ms → 1200ms`。每次都重新读取真实 `host.getConversationId()`，不保留、不猜测、不伪造 conversation identity。

真实 Codex Desktop：**PASS**。

### 2.2 Chat Earlier Navigation 提速

Chat Earlier 保持 progressive logical hydration，并增加受约束的性能优化：

- Chat motion progress gate：`8ms`；
- Earlier 自适应 jump scale：近距离 `1.35`、中距离 `1.55`、远距离 `1.75`；
- 极远距离且远离边界、无 stall 时启用 `chat-coalesced`，减少中段宿主虚拟窗口重建次数；
- Earlier 物理边界使用 progress-renewed boundary hydration，只有观察到真实 window / extent / index 结构进展才允许续期；
- Q1 持续有真实进展时仍允许超过 256 probes；
- 继续受 stall、inactivity、45 秒 absolute hard limit、verify/post-settle 约束。

真实长 Chat `Q76 → Q1`：**PASS**。相较 v0.5.0 明显提速；偶发 1～2 次宿主虚拟化卡顿仍可能出现，但不影响定位正确性。

### 2.3 Work Earlier Navigation 提速

Local Work 保留独立 wheel path，不与 Chat 路径合并。

保持不变的安全语义：

- 刚进入 Local Work 的 `500ms` restore settle gate；
- Codex++ `markPointerIntent` / `saveNow` 兼容路径；
- physical-tail verification；
- post-settle correction；
- Earlier boundary conservative hydration wait；
- fail-closed。

仅对长距离 Earlier wheel step 做保守自适应：

- 短历史 `≤12 Q`：半视口；
- 近距离：约 `720px`；
- 中距离：约 `864px`；
- 远距离：约 `972px`；
- 接近 Earlier 边界时自动缩到剩余距离。

真实 Work：**PASS / 无回弹**。

### 2.4 Guarded mounted fast settle

已挂载且稳定的目标允许受保护的 mounted fast settle；只有目标从导航开始就已存在，并且 Turn identity、visible signature、scroll extent、logical position 与目标 geometry 在稳定窗口内均不漂移时才提前成功。

通过 hydration 后才出现的目标继续走完整 post-settle，不使用快路径。

### 2.5 自动慢导航诊断

增加轻量、持久化的 slow navigation diagnostics：

- 自动记录慢导航与最近步骤；
- 支持 `chat-progressive` / `chat-coalesced` / `chat-boundary` / `work-wheel` 等模式；
- 记录 Q 顺序、host、耗时、visibleRange、scrollHeight、logicalPosition 等数值；
- 不持久化 conversation ID、Turn UUID 或正文；
- 最近慢记录跨 Codex 重启保留，用于区分脚本 pacing 与宿主 virtualization / hydration 卡顿。
