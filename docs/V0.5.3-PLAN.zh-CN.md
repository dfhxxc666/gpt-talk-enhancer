# GPT TalkEnhancer v0.5.3 规划

状态：Completed / release candidate
定位：Recovery & Consolidation
基线：f5ab9c4 之后的 rollback stabilization；release runtime 0.5.3
原则：不新增产品功能，不改变已经实机通过的 Chat / Work 用户行为。

## 1. 目标

v0.5.3 的任务是把 v0.5.2 回退后在 main 上逐步完成的稳定性修复，整理成一个可以长期维护、可以正式发布的新稳定基线。

重点不是继续增加能力，而是把当前已经通过实机验证的 Timeline 系统做完整收口。

## 2. 纳入的稳定行为

### Chat

固定验收以下形态：

- 普通 Chat。
- Pinned Chat。
- Project / 文件夹 Chat。
- 手机或其他设备创建、当前电脑无完整本地 cache 的 Chat。
- true-top bootstrap。
- loaded sweep。
- 视觉冻结与原位置恢复。
- identity gap 恢复。
- Q 导航后 inferred identity 恢复。
- Timeline cache 自愈。
- duplicate / missing order 检测。
- stale cache + occupied-order 自动重建。
- Timeline repair 与 Q navigation 互斥。

### Work

Work 行为冻结，不做重新设计：

- Work Earlier。
- Work Later。
- physical tail / final user turn backtrack。
- post-settle verification。
- Codex++ scroll restore 兼容。
- Local Work cache 与 Chat cache 隔离。

## 3. v0.5.3 必做项

1. 固化 Normal / Pinned / Project / Mobile Chat + Work 的实机验收矩阵。
2. 将当前回归测试整理为稳定 regression suite。
3. 将 orderHealth、bootstrap repair、identity recovery、navigation state 的诊断字段整理成明确分组。
4. 校验 Timeline cache restore 时的完整性与 order 不变量。
5. 明确 bootstrap、repair、navigation 三种 scroll ownership，保证互斥。
6. 清理测试名称、历史注释和文档里已经过时的 v0.5.2 current-stable 语义。
7. 更新 README、Known Issues、Acceptance、SHA 与安装说明。
8. release 前完成持续实机 soak。

## 4. 禁止项

v0.5.3 不允许：

- 新增 Timeline Search。
- 扩展 Prompt Library 产品功能。
- 自动运行 predictive fast path。
- 自动运行 Official Bridge navigation。
- 自动 Fiber / L3 deep scan。
- Pagebuster。
- 网络拦截作为正常运行路径。
- 合并 Chat / Work navigation。
- 合并 Chat / Work Timeline cache。
- 大规模 bootstrap.js 重构。
- Browser / Web 正式版重新开发。

## 5. 验收门槛

自动门禁至少包含：

- 全量 test PASS。
- build PASS。
- build:market PASS。
- node --check PASS。
- git diff --check PASS。
- CHAT_PREDICTIVE_FAST_PATH=ABSENT。

实机至少覆盖：

- 普通 Chat 长对话。
- Pinned Chat。
- Project / 文件夹 Chat。
- 手机创建 Chat。
- Chat 快速到顶。
- Chat Q1 / 中段 Q / 最后一问。
- Work Earlier / Later。
- Work 最后一问。
- Codex++ scroll restore 开关相关已知场景。

任何场景出现 Timeline 洞、上下跳动、跨会话串 cache、错误 identity 或导航目标错误，都阻塞 v0.5.3 发布。

## 6. 发布输出

通过后：

- runtime/version 正式 bump 到 0.5.3。
- 生成新的单文件 market build。
- 记录 SHA-256。
- 新建 v0.5.3 final acceptance。
- 创建 v0.5.3 tag。

在正式验收前不提前打 tag。

## 7. 向 v0.5.4 的交接

v0.5.3 发布后，正常运行路径冻结。

后续快路径研究必须在 v0.5.4 的独立实验框架内进行，不能直接把研究代码挂回普通 Timeline 点击或 DOM mutation 路径。
