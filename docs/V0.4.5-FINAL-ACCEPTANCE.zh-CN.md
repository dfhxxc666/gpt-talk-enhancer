# GPT TalkEnhancer 0.4.5 Final Acceptance

> 状态：**FROZEN / 最终稳定基线**
> 发布目标：`v0.4.5`
> 实现基线：`4d79a130940d70ab30eb88486ae97868530d4a2b`

## 1. 0.4.5 收口目标

0.4.5 只关闭 0.4.4 发布后剩余的 UI consistency 与布局问题，不重新设计已经实机稳定的 Navigation、TurnIndex、Timeline Cache、Capture 或 Prompt 核心。

本版本完成后，0.4.x 作为 GPT TalkEnhancer Desktop 当前稳定基线冻结。除非出现新的、可复现的回归 Bug，否则后续能力开发进入 0.5.0。

## 2. Tail Active consistency

0.4.4 已允许动态最后一问位于 `column-reverse` newest / physical tail 时按 Tail Verification 完成 Navigation verified success，但 ActiveTracker 仍坚持 120px activation line，因此可能出现：

```text
正文已正确定位 Q63
Navigation verified Q63
Timeline / Questions active 仍显示 Q62
```

0.4.5 在 Codex Desktop Host active 读取层新增极窄 Tail Active 规则：

- scroll container 必须为 `column-reverse`；
- 必须位于 physical tail；
- container 必须真实可滚动；
- User Turn 必须与 viewport 真实相交；
- 若还有后续 User Turn 位于 viewport 下方，则 fail-closed；
- 仅在满足上述条件时选择视觉位置最靠后的可见 User Turn；
- 其他情况完整回退原 `computeActiveTurnId()` activation-line 规则。

该修复没有修改 Navigation 状态机、hydration、动态 TurnIndex、Restore 或 Cache。

真实 Codex Desktop 验收：**PASS**。最后一问主体与 Timeline / Questions active 已一致。

## 3. Toast conversation viewport centering

此前 `.gte-toast` 使用固定 `left: 50%`，水平中心属于整个应用窗口。在左侧 sidebar、右侧 pane 等存在时，“正在定位 Qxx…”会相对实际会话区域偏移。

0.4.5 改为由 AppShell 已有 conversation viewport rect 动态提供 Toast 水平中心：

- sidebar 宽度变化时跟随；
- 右侧 pane 变化时跟随；
- window / visualViewport resize 时跟随；
- 缺少可靠 viewport rect 时回退原 `50%`；
- 不修改 Toast 垂直位置、显示时机、文案或 Navigation UX 状态。

真实 Codex Desktop 验收：**PASS**。

## 4. 自动回归

0.4.5 新增回归覆盖：

1. physical tail 选择最后一个真实可见 User Turn；
2. Host 级 Q62 activation-line → Q63 tail active override；
3. 非 physical tail 不启用 override；
4. 非 `column-reverse` 不启用 override；
5. 下方仍有 Turn 时 fail-closed；
6. Toast 使用 conversation viewport center；
7. AppShell viewport resize 同时更新 Timeline inset 与 Toast center。

最终发布门禁记录将在本文件第 7 节写入。

## 5. 0.4.x 冻结范围

以下能力以 0.4.5 为冻结基线：

- stable Local Thread identity：`local:<UUID>`；
- stable Local 优先级与 Conversation isolation；
- UUIDv7 Turn global reindex；
- Timeline Index Cache；
- dynamic TurnIndex Navigation target order；
- `column-reverse` monotonic Earlier hydration；
- Last Turn Tail Verification；
- Tail Active consistency；
- explicit Local Codex++ Scroll Restore；
- Navigation pending / supersede / failure UX；
- conversation-viewport Timeline / Toast layout；
- Prompt Picker / Prompt Library；
- media/settings/plugin surface hiding；
- Host Compatibility Diagnostics。

除非新的直接运行时证据证明存在回归，不继续调参或重新引入 0.4.4 已删除的滚动实验状态机。

- `workLongHistoryThreshold`；

- internal RPC；
