## 2. Chat 实机矩阵

### Normal Chat

- 短对话 Q1 / 中段 / 最后一问。
- 长对话 Earlier / Later。
- 快速到顶后再次点中段 Q。
- navigation 完成后 active 与正文一致。
- Timeline 无 duplicate / missing order。

### Pinned Chat

- 首次打开可建立 identity。
- 已有 cache 可恢复。
- identity gap 后可恢复。
- Load All 后 Timeline 不消失。
- 中段 Q 点击不出现上下振荡。

### Project / 文件夹 Chat

- 唯一标题 project-chat identity。
- fallback-turn 不产生跨 cache 假歧义。
- 首次加载完整 Timeline。
- 已加载后再次进入 Timeline 不空白。
- 重启后 stale cache 可自愈。

### Mobile / other-device Chat

- 当前电脑无完整 cache。
- true-top bootstrap 完成。
- visual freeze 不显示扫屏动画。
- column-reverse + windowOrder 可建立逻辑顺序。
- Q 编号连续。
- occupied-order / duplicate / missing order 可自动 rebuild。
- repair 期间点击 Q 不启动竞争 navigation。
- 修复完成后中段 Q 可稳定定位。

## 3. Work 实机矩阵

Work 行为冻结，只做回归：

- Earlier 单批加载。
- Load All 到 true top。
- Later。
- 最后一问。
- 长 assistant tail backtrack。
- post-settle verification。
- Codex++ markPointerIntent / saveNow 顺序。
- sidebar 切换前保存当前 Work scroll。
- Chat / Work cache 不串线。

## 4. Prompt / Surface

- New Chat 显示 Prompt Trigger。
- Conversation 显示 Prompt Trigger。
- Settings 不显示。
- host overlay blocker 生效。
- Prompt 新建 / 编辑 / 收藏 / 搜索 / 删除 / 插入。
- 不自动发送。

## 5. Release 阻塞条件

出现任一项即阻塞 v0.5.3：

- Timeline Q 编号洞。
- duplicate global order。
- navigation 上下振荡。
- 主体与 active Q 不一致。
- Chat / Work cache 串线。
- 会话切换后显示上一会话 Questions。
- Pinned / Project / Mobile Chat 空白。
- Work 已冻结行为回归。
- predictive fast path 意外进入正常运行时。
