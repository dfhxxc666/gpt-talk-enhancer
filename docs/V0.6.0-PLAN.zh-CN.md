# GPT TalkEnhancer v0.6.0 规划

状态：Planning
定位：Product Features
前置条件：v0.5.3 稳定发布完成；v0.5.4 研究结果已分级，不要求所有 fast path 实验成功。

## 1. 产品目标

v0.6.0 将开发重点从持续修补宿主导航，重新拉回 GPT TalkEnhancer 的两个核心产品面：

1. Conversation Timeline / Question List。
2. Prompt Picker / Prompt Library。

## 2. P0：Timeline Search

在 expanded Question List 中增加搜索。

范围：

- 只搜索 TurnIndex / Timeline Cache 已经知道的问题文本。
- 不为了搜索触发新的 DOM 全量扫描。
- 显示 Q 编号、命中片段和匹配数量。
- 点击搜索结果复用现有稳定 navigation。
- 支持快速清空搜索并返回完整 Question List。
- 搜索不改变 global order，也不改变 cache。

第一版不做 assistant 全文搜索。

## 3. P0：Prompt Library v2

在现有新建、编辑、删除、收藏、搜索、插入基础上增强：

- 标签或分组。
- JSON 导入。
- JSON 导出 / 备份。
- 最近使用。
- 更明确的 favorite / group / search 组合过滤。
- 保持只插入、不自动发送。

候选增强：

- 简单模板变量。
- 快捷键。

首版不做云同步。

## 4. P1：诊断体验

把目前依赖 DevTools 的诊断进一步产品化：

- 一键复制 Timeline / identity / navigation 诊断快照。
- 自动脱敏不必要的宿主细节。
- 明确显示当前 Chat / Work surface 与 Timeline health。
- 保留详细 debug API，不让普通 UI 常驻大量诊断内容。

## 5. 内部架构整理

v0.6.0 可以在完整回归保护下逐步拆分 bootstrap.js，但禁止一次性重写。

候选边界：

- ChatIdentityCoordinator。
- ChatBootstrapCoordinator。
- ChatTimelineRepair。
- TimelineNavigationState。

bootstrap.js 最终只保留 orchestration。

每次拆分必须行为等价，并单独通过全量测试与实机矩阵。

## 6. 与 v0.5.4 的关系

v0.5.4 的 fast path 只有 A 级候选才可进入正式运行时。

Timeline Search 和 Prompt Library v2 不依赖 fast path 研究完成。

如果 fast path 仍不稳定，v0.6.0 继续使用 v0.5.3 baseline navigation。

## 7. 明确暂缓

v0.6.0 暂缓：

- Browser / Web 正式版。
- 云同步。
- assistant 全文索引。
- 自动发送 Prompt。
- 网络拦截。
- Pagebuster。
- 自动 Fiber / L3 deep scan。
- Chat / Work cache 合并。

## 8. 建议实施顺序

Phase 0：架构边界与测试整理。

Phase 1：Timeline Search。

Phase 2：Prompt Library v2 的标签、导入导出、最近使用。

Phase 3：诊断入口。

Phase 4：评估 v0.5.4 A 级 fast path candidate 是否并入。

Phase 5：完整实机验收与 release 收口。
