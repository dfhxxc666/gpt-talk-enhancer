## 3. v0.5.3 Consolidation

### 3.1 TimelineCache restore health

TimelineCache 现在在恢复边界检查：

- invalid id。
- invalid / negative / fractional order。
- duplicate id。
- duplicate order。
- internal missing order。

健康 cache 正常恢复。

损坏 cache：

- 仅允许 self-describing fallback-turn / turn-index anchor salvage。
- UUID-only gapped / polluted cache 无可信 anchor 时直接 rejected。
- rejected cache 不会直接灌入 TurnIndex。

load diagnostics 会记录 healthy / empty / salvaged / rejected、sourceTurnCount、loadedTurnCount 与 health。

### 3.2 Atomic DOM snapshot replacement

TurnIndex.replaceDomSnapshot 现在要求候选 snapshot：

- id 全部有效且唯一。
- order 全部为非负整数且唯一。
- 从 0 开始连续。
- 当前 index 仍为 pure DOM。

候选不满足条件时直接返回 false，旧 TurnIndex 不被清空。

### 3.3 Scroll ownership

新增统一 scrollOwnership diagnostics：

- idle。
- chat-bootstrap。
- chat-repair。
- chat-earlier。
- work-earlier。
- navigation。
- conflict。

首次 Chat bootstrap 持有 scroll 时，manual Load All 不再启动第二个 Chat history hydration。

repair 期间现有 navigation 互斥规则继续保留。
