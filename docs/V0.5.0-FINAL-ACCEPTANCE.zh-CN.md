## 2. 主要完成项

### 2.1 Settings Prompt Surface 修复

Settings 不再显示 Prompt Trigger / Panel；普通设置页 textarea 不再误判为 New Chat Composer。进入 Settings 时已打开的 Prompt Panel 会关闭。

真实 Codex Desktop：**PASS**。

### 2.2 最大化 + 折叠侧栏 Timeline 可见性

Timeline 可见性与 Local sidebar selected row identity 解耦。宿主 selected row 短暂消失时，只保留已有 UI 视图，不伪造 Local identity，也不触发 reindex/cache/save/navigation。

真实 Codex Desktop：**PASS**。

### 2.3 Chat Earlier Navigation

真实诊断证明 Chat 同样可能为 `column-reverse`。0.5.0 不再使用 scroll model 猜 Chat/Work：

- Local Work Earlier：仅 `host=local + source=sidebar-local` 走 Work wheel；
- ChatGPT Earlier：走通用 progressive logical jump；
- Chat Q1 持续有真实进展时允许超过 256 probes；
- 仍受 stall、inactivity、45 秒 absolute hard limit、verify/post-settle 约束。

真实长会话 `Q76 → Q1`：**PASS**，并较旧错误 Work 路径明显加速。

### 2.4 Local Work Restore 竞态

刚进入 Local Work 时，宿主自己的 scroll restore 可能仍在执行。0.5.0 增加 500ms 的窄 settle gate，仅作用于刚点击切入 Local Work 后立即触发的 Timeline 导航。

真实短 Work 与长 Work 的倒数第二问/中间问回弹：**PASS**。

### 2.5 Timeline Desktop UI 微调

- Timeline conversation viewport 右侧安全 inset 最终定为 `14px`；
- 不遮挡官方滚动条；
- Rail hover detail 改为 `Qxx · 短摘要…`；
- `aria-label` 仍保留完整文本。

真实视觉验收：**PASS**。
