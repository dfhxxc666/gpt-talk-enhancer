# GPT TalkEnhancer v0.5.2 Final Acceptance

日期：2026-09-10
状态：**PASS / STABILITY & FAST-PATH RELEASE**

## 1. 版本定位

GPT TalkEnhancer v0.5.2 是基于 v0.5.1 Navigation Performance baseline 的稳定性与快路径收口版本。

本版本不增加新的产品主功能，继续聚焦：

1. Conversation Timeline / Question List
2. Prompt Picker / Prompt Library

本次重点是减少 Work 双向长历史导航的顿挫、修复 Codex++ scroll restore 冲突、改善 Questions 打开性能，并把高成本 Official Navigation / Fiber 研究从正常运行路径冻结。

## 2. 主要完成项

### 2.1 Questions 展开性能

打开 60+ Questions 时，原同步 `scrollIntoView()` / geometry 链会制造明显卡顿。

v0.5.2 改为：

- panel 显示前读取 anchor geometry；
- 避免同一 click stack 中额外强制 layout；
- active-row follow 延迟到下一帧；
- close / destroy 时取消 stale follow；
- 不虚拟化问题列表，不截断问题原文。

真实 Codex Desktop：**PASS / 卡顿明显改善。**

### 2.2 Work Later 双向 wheel acceleration

v0.5.1 已有 Work Earlier 专用 wheel path，但 Later 仍会回退到通用 progressive hydration，等待更长且有明显顿挫。

v0.5.2 将 stable `sidebar-local + column-reverse` 的 Later 纳入同一 Work wheel engine：

```text
Earlier = -1 wheel
Later   = +1 wheel
```

Later 保留 distance-adaptive step、tail 收敛、physical-tail verification 与 post-settle。

真实 Codex Desktop：**PASS / 向下卡顿感消失。**

### 2.3 Codex++ scroll restore 防回弹

Codex++ 开启“切换对话保留位置”时，GPT TalkEnhancer Work Timeline 导航曾在完成后发生底部回弹。

当前顺序：

```text
Timeline click
→ markPointerIntent
→ Local settle
→ Work navigation
→ verified
→ saveNow
```

真实 Codex Desktop：**PASS / 选项开启时回弹消失。**

### 2.4 sidebar 切换前保存最新滚动位置

修复用户已经手动浏览到更后位置，但 Codex++ 仍恢复较旧保存点的问题。

stable Local thread 离开前，在 sidebar click capture phase 先执行当前 thread 的 `saveNow()`；点击当前同一 thread 时不重复强制保存。

真实 Codex Desktop：**PASS / `Q63 → 切走 → 返回 Q54` 不再出现。**

### 2.5 Prompt 宿主浮层遮挡

Prompt 触发按钮原本可能压在 Codex 的 thread hover card / 临时浮层之上。

v0.5.2 增加窄范围 host overlay blocker：

- 真正的 visible dialog / aria-modal 继续阻止 Prompt；
- 非模态 popper/menu/listbox/tooltip 只有在进入 composer/Prompt 邻近区域时才阻止；
- 远离 composer 的普通 tooltip 不影响 Prompt；
- 浮层关闭后 Prompt 恢复。

真实 Codex Desktop thread hover card：**PASS。**

Work 模型选择 popup 本轮没有再次稳定复现，因此不把它单独记作真实验收；当前通用 blocker 已覆盖同类宿主浮层条件。

### 2.6 L3 / Official Navigation runtime freeze

研究代码保留，但真实运行发现自动 Fiber/key-join 深扫会造成 Codex 主线程明显卡顿。

正式 v0.5.2 固定：

```js
const OFFICIAL_NAVIGATION_RUNTIME_ENABLED = false;
const L3_RUNTIME_ENABLED = false;
```

正常产品运行时不再自动执行 post-nav L3、adaptive rescan、mutation recovery 或 host internal depth probe。

手动研究入口保留：

```js
window.__GPTTalkEnhancerV3.runL3ResearchScan()
```

真实 Codex Desktop：**PASS / runtime freeze 后 Timeline 点击不再造成整机卡顿。**

详细研究基线见 `docs/V0.5.2-FAST-PATH-CHECKPOINT.zh-CN.md`。
